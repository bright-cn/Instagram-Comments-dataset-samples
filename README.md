此 **Instagram 评论数据集样本**包含 **1,061 条记录**，并通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | 评论发布所在 Instagram 账号的 URL。 |
| `comment_user` | 发表评论者的用户名。 |
| `comment_user_url` | 评论用户的 Instagram 个人资料 URL。 |
| `comment_date` | 评论的发布日期和时间。 |
| `comment` | 用户发布的评论内容。 |
| `likes_number` | 评论获得的点赞数。 |
| `replies_number` | 评论的回复数。 |
| `replies` | 评论回复的内容（如有）。 |
| `hashtag_comment` | 评论内容中包含的所有话题标签。 |
| `tagged_users_in_comment` | 评论内容中标记的用户名。 |
| `post_url` | 评论所在 Instagram 帖子的 URL。 |
| `post_user` | 原始帖子发布者的用户名。 |
| `comment_id` | 评论的唯一标识符。 |
| `post_id` | Instagram 帖子的唯一标识符。 |


## 使用场景

### 1. 情感分析
分析评论的情感倾向，了解公众对 Instagram 帖子的看法和品牌情感。

### 2. 网红互动分析
通过分析评论区中的用户互动来识别关键网红，从而优化营销策略。

### 3. 趋势检测
监测评论中的话题标签和被标记用户，实时发现新兴趋势和话题。
