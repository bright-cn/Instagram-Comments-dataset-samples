此 **Instagram 评论数据集样本**包含 **1,061 条记录**，通过 **Bright Data API** 提取。

## 数据字段

| 字段名 | 说明 |
|------------|-------------|
| `url` | 发布该评论的 Instagram 账号页面 URL。 |
| `comment_user` | 发表评论的用户的用户名。 |
| `comment_user_url` | 评论用户的 Instagram 个人主页 URL。 |
| `comment_date` | 评论发布的日期和时间。 |
| `comment` | 用户发表的评论内容。 |
| `likes_number` | 评论获得的点赞数。 |
| `replies_number` | 评论收到的回复数。 |
| `replies` | 对该评论的回复内容（如有）。 |
| `hashtag_comment` | 评论内容中包含的话题标签。 |
| `tagged_users_in_comment` | 评论内容中标记的用户名。 |
| `post_url` | 该评论所属的 Instagram 帖子 URL。 |
| `post_user` | 原帖发布者的用户名。 |
| `comment_id` | 评论的唯一标识符。 |
| `post_id` | Instagram 帖子的唯一标识符。 |

## 使用场景

### 1. 情绪分析
分析评论中的情绪倾向，了解公众对 Instagram 帖子及品牌的看法。

### 2. 网红互动分析
分析评论区的用户互动，识别具有影响力的创作者，从而优化营销策略。

### 3. 趋势发现
监测评论中的话题标签和被标记的用户，及时发现新兴趋势与热门话题。
